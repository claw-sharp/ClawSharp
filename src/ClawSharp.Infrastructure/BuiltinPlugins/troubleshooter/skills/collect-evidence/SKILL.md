# Collect Evidence

Use this skill before fixing a bug when the report is vague or incomplete.

## Gather

- Exact reproduction steps
- The failing command, request, or screen
- The error text or unexpected output
- The file or subsystem most likely involved

## Rules

- Prefer direct artifacts over interpretation.
- If a command fails, keep the exact exit status and the key lines.
- If the failure is visual, capture a screenshot and the console state.
- If information is still missing after local inspection, ask one focused follow-up question.
