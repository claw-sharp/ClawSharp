# React Review

Use this skill when recent changes touch TSX or JSX components.

## Focus Areas

- Component structure: avoid wrapper soup, duplicated layout shells, and props that should stay local.
- Hooks: check dependency correctness, unnecessary effects, mirrored state, and cleanup gaps.
- Accessibility: semantic elements, keyboard access, labels, and interactive roles.
- Rendering cost: unstable list keys, repeated work during render, and avoidable rerenders.
- TypeScript: event types, prop shapes, and stringly-typed component contracts.

## Review Style

Prefer a short list of concrete issues over a broad lecture.
If the file is already in good shape, say so plainly.
