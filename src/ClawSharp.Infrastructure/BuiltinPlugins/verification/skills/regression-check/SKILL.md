# Regression Check

Use this skill near the end of a task to verify the change, not just compile it.

## Checklist

- Run the narrowest useful automated test command.
- Exercise the changed path manually or through browser automation when user-visible behavior changed.
- Check for obvious collateral damage in nearby flows.
- Prefer evidence over claims: command result, screenshot, or a specific observed outcome.

## Output

Report what you checked, what passed, what failed, and what remains unverified.
