# ClawSharp Brand Assets

This folder contains brand assets extracted from the guideline sheet at `assets/source/clawsharp-brand-guidelines.png`.

Regenerate the raster exports with:

```powershell
./assets/extract-brand-assets.ps1
```

Main outputs:

- `logos/logo-dark.png`
- `logos/logo-light.png`
- `logos/mark-dark.png`
- `logos/mark-light.png`
- `logos/wordmark-dark.png`
- `logos/wordmark-light.png`
- `favicons/favicon-dark-512.png`
- `favicons/favicon-dark-32.png`
- `favicons/favicon-light-512.png`
- `favicons/favicon-light-32.png`
- `branding/website-header-light.png`
- `branding/terminal-ui-dark.png`
- `branding/mobile-app-icon.png`

Brand colors copied from the guideline sheet are recorded in `assets/brand.json`.
